# judge-laugh-developer

A program that writes one funny single-line excuse a developer gives when
code breaks in production to `/output/entry.txt`. Built for the make.fun
competition **"Make the AI Judge Laugh: Developer Excuses"**
(`u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3`).

## The text

> It works on my machine — which has never met a real user.

57 characters. It turns the most worn developer excuse inside out: the
machine was never the problem — the users were. The machine worked fine
precisely because no real user had ever touched it. It sounds like something
a developer would actually say out loud after an incident, and it lands in
one breath, with nothing left to trim.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
